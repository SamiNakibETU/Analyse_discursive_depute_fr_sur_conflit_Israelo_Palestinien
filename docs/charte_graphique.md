# Charte graphique

Les figures de `sorties/figures/` suivent ces règles.

| Rôle | Valeur |
|---|---|
| Fond | blanc `#FFFFFF` |
| Texte, traits | `#111111` |
| Filets, grilles | `#D4D0CA` |
| Métadonnées | `#888888` |
| Accent unique | `#E8413C` |

Blocs : gauche radicale en rouge `#E8413C`, gauche modérée en rouge clair `#F2A29F`, Centre en gris `#8C8C8C`, droite en noir `#111111`.

Polices : Barlow Condensed pour les titres et étiquettes, Barlow pour le texte, Courier Prime pour les valeurs. Elles sont téléchargées depuis Google Fonts (licence OFL) au premier lancement ; à défaut, les figures utilisent DejaVu Sans.

Chaque figure porte un numéro, un titre qui énonce le résultat, une phrase de méthode, la source et le nom de l'auteur. Une seule couleur d'accent, réservée à ce qui porte l'argument.
